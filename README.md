# Telecom Customer Churn Prediction & Explainability

## 🚀 Project Overview
This repository contains an end-to-end MLOps pipeline for predicting telecom customer churn using a custom **1D CNN-BiLSTM Hybrid Attention Neural Network**. It includes Explainable AI (XAI) capabilities using SHAP, LIME, and PDP.

## 🎥 Video Demonstration
[Click here to watch the full web-deployed demonstration](https://github.com/FanuelMichael/Predict-and-explain-telecom-customers-churn/releases/download/v1.0/Web-deployed-demonstration.mp4)

## 🛠️ Tech Stack
*   **Deep Learning:** TensorFlow, Keras
*   **API:** FastAPI
*   **XAI:** SHAP, LIME, PDP
*   **MLOps:** Docker.
